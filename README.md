# Quem eu quero ser hoje?

Letters from Heart — apresentação interativa de cartas, em estilo medieval e à luz de velas.

## Preparação para Vercel

Site estático (HTML, CSS, JavaScript e assets locais), sem dependências ou variáveis de ambiente. Importe este repositório em Vercel, escolha **Other**, mantenha o diretório raiz e deixe Build Command e Install Command vazios. O projeto completo deve ser enviado antes do deploy.

## Privacidade

Este repositório é público. Revise as cartas antes do envio, pois relatos pessoais podem permitir identificação indireta mesmo sem nomes. Não inclua os manuscritos originais. Prefira repositório privado e acesso restrito para material escolar.
